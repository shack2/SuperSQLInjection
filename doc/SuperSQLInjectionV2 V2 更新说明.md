# 超级SQL注入工具 V2 · 更新说明

版本：V2.0.0（基于 V1.0 正式版升级）
发布日期：2026-09

V2 是超级SQL注入工具（SSQLInjection）的跨平台重写版本。V1 基于 WinForms / .NET Framework 4.0，仅支持 Windows；V2 在**完整保留 V1 核心注入能力**的前提下，对架构、检测引擎、利用能力与使用体验做了全面升级。以下按模块说明新增与优化点。

---

## 一、平台与架构（重写）

| 项 | V1 | V2 |
| --- | --- | --- |
| 运行平台 | 仅 Windows（WinForms + .NET Framework 4.0） | **Windows / macOS / Linux**（Avalonia + .NET 10） |
| 程序形态 | 单一 GUI | **GUI + 命令行 + DNSLog 服务**三形态，共用同一核心引擎 |
| 命令行 | 无 | **新增 SuperSQLInjectionV2.Cmd**：Native AOT 单文件（win-x64 / linux-x64 / osx-arm64），免 .NET 运行时，支持脚本化批量检测与取数 |
| DNS 外带接收 | 无 | **新增 SuperSQLInjectionV2.DnsServer**：可部署到 VPS 的自建 DNSLog 服务（ceye 兼容 API），另支持公共 DNSLog 平台与本机内置接收 |
| 代码架构 | 单工程 | 核心库 / GUI / 命令行 / DnsServer **四工程分离**，取数语句、检测用例全部配置驱动（`config/` 目录），不改代码即可扩展 |
| AI 集成 | 无 | 内置 **supersqlinjectionv2-cmd 智能体技能包**，可被 Kimi Work 等 AI 智能体调用，自然语言驱动检测与取数 |

## 二、注入检测引擎（全面重构）

- **新增检测分级**：Level 1–5 / Risk 1–3 用例分级（V1 无级别概念），可按需控制检测广度与 payload 风险。
- **新增检测技术**：在 V1 的 Bool 盲注 / 报错 / Union / 时间盲注之上，新增**堆叠注入（S）**与 **DNS 外带注入（D）**，组合为 BEUTSD 六种技术，可自由筛选。
- **Bool 盲注抗噪升级**：V1 依赖关键字 / 状态码 / 长度比对；V2 升级为**网页相似度为主的抗噪判断**（关键字 / 相似度 / 比值三路印证），自动识别软 404、WAF 拦截页与页面动态噪声，误报率显著降低。
- **新增智能模式 / 穷举模式**：智能模式高命中用例优先 + 启发式跳过；穷举模式不剪枝跑完全量用例。
- **检测用例可视化管理**：全部 payload 按数据库 × 注入类型 × Level/Risk 组织，界面化增删改，即时生效（V1 需手工编辑配置文件）。
- **报错指纹库独立管理**：指纹库 `errors.xml` 提供**分页可视化管理**界面，可在线新增 / 编辑 / 删除。
- **检测结果自动标注**：命中后自动标注注入点位置、注入类型、数据库类型，直接进入注入记录。
- **时间盲注实测值记忆**：检测记录保存实测延时值，恢复配置后自动带出到时间盲注通道。

## 三、数据库支持（8 种 → 14 种）

| V1 已支持（保留） | V2 新增 |
| --- | --- |
| MySQL、SQLServer、Oracle、PostgreSQL、Access、DB2、SQLite、Informix | **达梦（DM）、人大金仓（Kingbase）、openGauss、ClickHouse、H2、HSQLDB** |

每种数据库的取数语句（版本 / 库表列 / 文件 / 命令）均为独立模板文件，可界面化维护扩展。

## 四、数据获取增强

- **大表 dump 分片读取 + 断点续传**：LIMIT 分页取数，中断后可从上次行号继续（V1 大表易卡死、中断需重来）。
- **Union 批量聚合取数**：聚合函数多行拼单行一次回显（k 行 1 次请求），截断 / 取空自动回退逐行，Union 通道取数提速一个量级。
- **盲注智能加速（新增）**：在线学习 / 值预测、n-gram 字符预测、值缓存，在 V1 二分法基础上进一步压缩发包次数；库表列枚举命中即实时上树。
- **中文识别保留并完善**：HEX 包装取数防乱码，覆盖更多字段类型与空值场景。
- **取数动作补全**：环境变量、库 / 表 / 列 / 行数据之外，新增 / 完善 **Hash 读取、权限角色枚举、自定义 SQL 执行**（多行结果表格化）。
- **取数模板可视化**：各数据库 × 各注入类型的取数 SQL 模板界面化查看维护（V1 为纯文本配置）。

## 五、文件读写与命令执行增强

| 能力 | V1 | V2 |
| --- | --- | --- |
| MySQL 命令执行 | 无 UDF 通道 | **内置 lib_mysqludf_sys 二进制**，Union 写库到 plugin 目录 + `CREATE FUNCTION sys_eval` 一键完成 UDF 提权执行 |
| SQLServer 命令执行 | xp_cmdshell | xp_cmdshell（自动开启组件）+ **sp_OACreate(wscript.shell) 兜底**（xp 被删时用，输出经 BULK INSERT 回读） |
| SQLServer 写文件 | 写后不校验 | **写后自动验证**：xp_fileexist 确认存在 + BULK INSERT 回读内容比对；sp_MakeWebTask 已在新版移除等静默失败场景明确提示 |
| PostgreSQL | 文件读写 | 文件读写 + **UDF / COPY FROM PROGRAM 命令执行** + **大对象 lo_import/lo_export 单语句读写**（Union/报错通道即可，免堆叠） |
| Oracle | — | **GETXML + Java 存储过程命令执行/文件读写**（`dbms_xmlquery.getxml` 在 SELECT 中执行匿名 PL/SQL 部署 Java，免堆叠；**限 9i~11g**，18c 弃用该包/21c+ 移除，XE 无 JVM 不可用） |
| 达梦 | — | 不支持（实测 DM8 无 DBMS_XMLQUERY 包，驱动堆叠禁 DDL，纯注入不可达） |
| Kingbase | — | 复用 PostgreSQL 通道：COPY 文件读写 + COPY FROM PROGRAM 命令执行 |
| H2 | — | CSVREAD/CSVWRITE 文件读写（裸字节落盘，免表头免引号包裹）+ **CREATE ALIAS Java 函数命令执行**（需 JDK 编译器 javax.tools 可用，实测 H2 1.4/2.x 均支持） |
| SQLite | — | ATTACH DATABASE 写 WebShell（堆叠） |
| ClickHouse | — | `file()` 读文件（user_files 目录）；不支持写文件（`INTO OUTFILE` 为 clickhouse-client 客户端侧功能，HTTP 接口固定报错 358，注入场景不可用） |
| MySQL 写文件 | Union 写文件 | Union 写文件 + **general_log 写 WebShell**（堆叠） |
| 命令输出体验 | 一次性回显 | **逐字符实时回显**，自动净化通道产生的多余换行 |
| 读文件 | 按库选语句 | 下拉选择通道，结果从首行展示，支持复制导出 |

## 六、防护绕过增强

- **新增自定义 JS tamper**：内置 QuickJS 引擎，实现 `function tamper(payload)` 即可编写绕过脚本，界面化管理；V1 仅支持固定字符替换。
- **内置编码工具链**：多种编码 / 混淆变换可**多选链式组合**（V1 为单一替换规则）。
- **新增 Chunked 分块传输、HPP 参数污染**绕过。
- **动态值抓取升级（新增脚本方式）**：支持字符串截取或 JS 脚本从完整响应报文抓取动态值 / Token，目标 URL 支持 GET/POST 或直接编辑报文（V1 仅固定规则的随机 Token / rand 标记）。
- **动态规则统一模型（动态值 + 二次注入整合，原"伴随请求"升级改名）**：动态值（主请求前取值回填 `<DRule>` 标记）与二次注入（主请求后追加回显页请求、响应替代主响应取数）合并为同一套规则模型，**管理入口迁移至防护绕过页"动态规则"选项卡**（内嵌"动态规则 / 脚本管理"两个子选项卡）；以 **TableView 规则列表 + 新增/编辑弹窗**管理（弹窗内请求报文带 HTTP 语法高亮）；**动态值可多条同时启用，二次注入同时只能启用一条**（开启一条自动关闭其余）；**每条规则可设标记名**，请求报文右键"插入动态值"点击规则即启用并在报文中插入 `<DRule>标记名:占位值<DRule>` 标记（有选区时保留选区作占位值，发送时整块替换；无选区在光标处插入空标记），右键"二次注入"单选开启一条二次注入规则；多规则并存时通过标记名精确关联（不带标记名时关联第一条启用规则）；**动态值取值来源三种：报文抓取 / URL（GET/POST）抓取 / 脚本生成**——脚本生成不发抓取请求，以主请求报文为输入输出动态值，可对报文做签名（API 接口场景）；动态值脚本分**请求抓取 / 自主生成**两类型，规则弹窗按来源自动过滤可选脚本并可现场"添加脚本"；弹窗内置"测试抓取动态值"保存前验证；二次注入请求 `<Rand>` 按请求流自动配对（FlowRand），多线程取数不再交错错配、无需限单线程（V1 二次注入多线程需手动限 1 线程）。
- **随机 UA / UA 池**、**代理池可用性验证 + 失败自动轮换**（V1 代理池仅随机选取）。
- 保留 V1 主要绕过手段：字符替换（正则 / 编码前处理）、随机大小写、Base64、Hex、延时 / 限速等。

## 七、网络与协议

- **新增 HTTP 认证**：Basic / Digest / NTLM。
- **新增跟随 302、失败重发策略**（次数 / 间隔 / 条件）。
- 保留 V1 优势：HTTPS 注入、注入标记可打在报文任意位置、HTTP / SOCKS5 代理。

## 八、界面与交互（重构）

- **现代化 UI**：Avalonia 重写，**明暗双主题**、统一设计令牌、GroupBox 分区卡片、矢量图标体系。
- **代码编辑器**：请求报文编辑采用 AvalonEdit（等宽字体 JetBrains Mono 等），注入标记 / 动态值 / 编码标记一键插入。
- **注入记录升级**：V1 仅记录注入类型；V2 支持**多条件搜索、详情回放、一键恢复配置并跳转取数**，多目标随意切换。
- **请求日志**：全量请求 / 响应留痕，可过滤、查看完整报文、单条回放。
- **取数过程实时反馈**：库表列枚举逐节点更新、字典猜解命中即上树、命令输出逐字符刷新（多线程事件通知驱动，界面不卡）。
- **编码工具独立成页**：URL / Base64 / Hex / HTML 实体 / Unicode / MD5 等常用变换。

## 九、运维与更新

- **软件更新检测升级**：在线检查新版本，下载更新包后解压覆盖即完成升级（V1 为更新提示 + 自动下载程序）。
- **更新配置收敛到文件**：更新服务地址 / 应用标识 / 渠道 / 客户端Key 统一写入 `config/update.ini` 随包分发（带默认值），UI 不再提供修改入口，避免误改；改文件后重启生效，文件缺失自动按默认值重建。
- **新增问题反馈**：关于页在线提交问题 / 建议（自动附带版本号）。
- **状态栏注入状态三态**：待检测 / 存在注入 / 未检测到注入，语义清晰。

## 十、功能调整说明（V1 有、V2 未保留）

| V1 功能 | V2 状态 |
| --- | --- |
| 批量爬行扫描注入（导入域名列表批量扫） | 未迁移（可改用命令行版脚本化批量检测） |
| 二次注入（取数） | **保留并升级**：与动态值统一为"动态规则"模型（防护绕过页-动态规则选项卡，动态值=取值回填 `<DRule>` 标记、二次注入=回显页响应替代主响应）；二次注入请求中的 `<Rand>` 按请求流自动配对（FlowRand），多线程取数不再交错错配、无需限单线程；仅注入检测页的二次注入选项卡已移除 |
| MD5 在线解密（第三方接口） | 未迁移（接口多已失效，保留本地 MD5 编码） |
| 注入绕过模板保存 | 由自定义 JS tamper 脚本管理替代 |
